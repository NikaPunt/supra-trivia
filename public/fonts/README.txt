Self-hosted fonts, all SIL Open Font License 1.1 (see the OFL-*.txt files here):
Fraunces (variable), Alegreya Sans, Bricolage Grotesque, Noto Sans Georgian, Noto Serif Georgian.
Subsets are from the Fontsource packages. Nothing is loaded from a third party.

Browsers keep these files for a year (see src/app.ts). If you change a font, give the file a new name and
update styles.css (and js/theme.js, which asks for each look's main fonts early), or phones will keep the old one.
